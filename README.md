## 📌 Описание

`Projectcours3` — консольное приложение для анализа банковских транзакций.  
Считывает операции из Excel-файла и предоставляет:

- отчёт по тратам в категории за указанную дату;
- агрегированные данные по расходам/доходам;
- поиск по описанию и по номеру телефона;
- анализ выгодных категорий кешбэка;
- курсы валют и цены акций для отображения на главной странице.

## 🧩 Установка

1. Клонировать репозиторий:
```
   git clone https://github.com/mrtimpr/Projectcours3.git
   cd Projectcours3
```
Создать виртуальное окружение:

```
python -m venv .venv
```
Активировать:

Windows:

```
.venv\Scripts\activate
```
macOS/Linux:

```
source .venv/bin/activate
```
Установить зависимости:

```
pip install -r requirements.txt
```
## 🛠 Использование
### 📄 1. Главная страница
Показывает агрегированные данные расходов, доходов, курсы валют и цены акций.

Запустить:

```
Выбери пункт меню: 2
Введите дату и время (YYYY-MM-DD HH:MM:SS)
```
### 🧾 2. Отчёт: траты по категории
Показывает операции по категории за выбранную дату.

Запустить:

```
Выбери пункт меню: 1
Введите номер категории
Введите дату (YYYY-MM-DD)
```
### 💳 3. Анализ выгодных категорий кешбэка
Показывает сумму кешбэка по категориям за год и месяц.

Запустить:
```
Выбери пункт меню: 3
Введите год
Введите месяц (1–12)
```
### 🔍 4. Простой поиск
Поиск по описанию и категории.

Запустить:
```
Выбери пункт меню: 4
Введите строку для поиска
```
### 📞 5. Поиск по номеру телефона
Находит все транзакции, содержащие номера телефонов в описании.

Запустить:
```
Выбери пункт меню: 5
```
